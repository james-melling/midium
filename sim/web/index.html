Inputs

Each button sends real traffic into IN A or IN B at MIDI wire speed: 31,250 baud, 320 µs per byte.

Outputs

Every byte the engine sends, timestamped as it starts on the wire, grouped into messages. Newest first.

noteCC / bend / aftertouchprogram / system common sysex / MSC / MTC fullrealtime / quarter frame

Default routing is the firmware default: IN A goes to both outputs and IN B is monitored only. Change it on the device under Menu > Routing. Settings live in RAM, as on the M1 hardware, so a power cycle or display change resets them.
